# Публикация на GitHub Pages

Загружайте в репозиторий содержимое этой папки, а не саму папку и не старые ZIP-архивы.

В корне репозитория должны находиться:
- `index.html`
- `styles.css`
- `roots-project.html`
- `hsbc-project.html`
- папка `assets`
- файл `.nojekyll`

В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main`, каталог `/ (root)`.

Видео обложек уже включены в `assets/main-v2`. Они настроены на автоматическое воспроизведение без звука и повтор по кругу.
